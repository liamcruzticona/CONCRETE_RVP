1. DISCRETIZACION POR CUANTILES
   Dataset: 1030 registros, 9 columnas
----------------------------------------------------------------------

  QUE ES: Convertir valores continuos (ej: Cement = 350.5 kg/m3) en
  categorias discretas (0, 1, 2, 3) para poder aplicar Entropia y MI.

  FORMULA DE CUANTILES:
    Dado un conjunto de N valores ordenados, el cuantil q (0 < q < 1)
    es el valor que deja q*N observaciones por debajo.

    Para 4 categorias (cuartiles): q1=0.25, q2=0.50, q3=0.75.

  EJEMPLO REAL: Variable Cement (1030 valores)

      Q3 (75%) = 350.0 kg/m3    -> valores 273-350  -> categoria 2
      Max = 540 kg/m3           -> valores 350-540  -> categoria 3

    Resultado:
      Cement=540  -> categoria 3 (esta en el cuartil mas alto)
      Cement=332  -> categoria 2
      Cement=142  -> categoria 0
      Cement=220  -> categoria 1

  CATEGORIAS DE LAS 8 VARIABLES (discretizadas sobre 1030 registros):
    Cement:       4 categorias (0,1,2,3)
    Slag:         3 categorias (0,1,2)
    FlyAsh:       2 categorias (0,1)

2. ENTROPIA DE SHANNON  H(X) = -SUM P(x) * log2 P(x)
   Ejemplo: H(Slag) en BEST (507 registros)
----------------------------------------------------------------------

  FORMULA:
    H(X) = - SUM_{x en X} P(x) * log2( P(x) )

    Unidades: bits. H_max = log2(k) para k valores equiprobables.

  DATOS DE ENTRADA (Slag en BEST, 507 registros):
    Slag tiene 3 valores posibles: {0, 1, 2}
    Frecuencias: Slag=0 -> 217 registros
                 Slag=1 -> 163 registros
                 Slag=2 -> 127 registros
                 Total   = 507

  PASO 1 - Calcular probabilidades P(x) = frecuencia / total:
    P(Slag=0) = 217 / 507 = 0.4280
    P(Slag=1) = 163 / 507 = 0.3215
    P(Slag=2) = 127 / 507 = 0.2505

    Verificacion: 0.4280 + 0.3215 + 0.2505 = 1.0000 OK

  PASO 2 - Calcular logaritmos en base 2 de cada probabilidad:
    Recordar: log2(x) = ln(x) / ln(2)

    log2(0.4280) = -1.2243
    log2(0.3215) = -1.6376
    log2(0.2505) = -1.9972

    NOTA: Los logaritmos son NEGATIVOS porque 0 < P < 1.
    El signo "-" fuera de la sumatoria los convierte en positivos.

  PASO 3 - Multiplicar cada P(x) por su log2 P(x):
    0.4280 * (-1.2243) = -0.5240
    0.3215 * (-1.6376) = -0.5265
    0.2505 * (-1.9972) = -0.5003

  PASO 4 - Sumar los tres terminos:
    SUMA = (-0.5240) + (-0.5265) + (-0.5003) = -1.5508

  PASO 5 - Cambiar el signo (el "-" de la formula):
    H(Slag) = -(-1.5508) = 1.5508 bits ~ 1.551 bits (redondeado)

  PASO 6 - Comparar con la entropia maxima:
    H_max = log2(3) = 1.585 bits  (si los 3 valores fueran equiprobables)

    Porcentaje usado: 1.551 / 1.585 = 97.9%

  INTERPRETACION: Slag esta usando casi toda su entropia maxima.
    Esto significa que los 3 valores de Slag aparecen con frecuencias
    muy similares en BEST. La distribucion es casi uniforme.

  TABLA COMPLETA DE ENTROPIAS (BEST, 507 registros):
    Variable      H(X) bits   H_max    % usado   Interpretacion
    -----------------------------------------------------------
    Cement        1.880       2.000    94.0%     Balanceada
    Slag          1.551       1.585    97.9%     Casi uniforme
    FlyAsh        0.747       1.000    74.7%     Un valor domina
    Water         1.929       2.000    96.4%     Muy balanceada
    Superp        1.574       1.585    99.3%     Casi uniforme
    CoarseAgg     1.959       2.000    97.9%     Muy balanceada
    FineAgg       1.979       2.000    99.0%     La mas uniforme
    Age           1.795       2.000    89.7%     Balanceada

  PREGUNTA DE EXAMEN:
    "Por que H(FlyAsh)=0.747 y H(Slag)=1.551 si ambas estan en BEST?"
    -> FlyAsh solo tiene 2 valores y P=1 domina (H_max=1.00).
       Slag tiene 3 valores distribuidos uniformemente (H_max=1.585).
       Mas valores + mas uniformidad = mas entropia.

    Find(x): busca el REPRESENTANTE del componente de x.
             parent[x] -> ... -> representante (compresion de ruta).
    Union(x,y): si Find(x) == Find(y) -> RECHAZAR (ciclo).
                Si no, unir por rango y ACEPTAR.

  EJEMPLO PASO A PASO (primeras 10 aristas):

7. RED BAYESIANA - Orientacion con BIC/AIC
   Ejemplo: Water vs Superplasticizer en BEST (507 registros)
----------------------------------------------------------------------

  CONCEPTO: Para cada arista del MST, decidir la DIRECCION de la flecha
  usando criterios de informacion (BIC y AIC).

  FORMULAS:
    BIC = -2 * ln(L) + k * ln(n)
    AIC = -2 * ln(L) + 2*k

    L = verosimilitud del modelo (producto de probabilidades condicionales)
    k = numero de parametros libres
    n = numero de registros

    MENOR BIC/AIC = MEJOR modelo

  EJEMPLO: Water -- Superplasticizer (MI=0.583, BEST, n=507)

  PASO 1 - Tabla de contingencia (de la seccion 3):
    Ya tenemos las frecuencias conjuntas y marginales.

  PASO 2 - Modelo A: Water -> Superplasticizer
    k_A = (cat_Water - 1) * cat_Superp = (4-1) * 3 = 9 parametros
    L_A = producto sobre los 507 registros de P(Superp | Water)

    log(L_A) = SUM_{celdas} count * ln( P(Superp | Water) )
             = SUM de 12 terminos (uno por celda)
             = -370.12  (aproximado)

    BIC_A = -2 * (-370.12) + 9 * ln(507)
          = 740.24 + 9 * 6.228
          = 740.24 + 56.05
          = 796.29

    AIC_A = -2 * (-370.12) + 2 * 9
          = 740.24 + 18
          = 758.24

  PASO 3 - Modelo B: Superplasticizer -> Water
    k_B = (cat_Superp - 1) * cat_Water = (3-1) * 4 = 8 parametros
    L_B = producto de P(Water | Superp)

    log(L_B) = -493.58  (aproximado)

    BIC_B = -2 * (-493.58) + 8 * ln(507)
          = 987.16 + 8 * 6.228
          = 987.16 + 49.82
          = 1036.98

    AIC_B = -2 * (-493.58) + 2 * 8
          = 987.16 + 16
          = 1003.16

  PASO 4 - Comparar y decidir:
    BIC_A (796.29) < BIC_B (1036.98) -> BIC dice Water -> Superp
    AIC_A (758.24) < AIC_B (1003.16) -> AIC dice Water -> Superp

    AMBOS COINCIDEN -> Water -> Superp (BIC y AIC)

  INTERPRETACION:
    El modelo "Water predice Superplasticizer" es mucho mejor que el
    inverso. Cuando se conoce la cantidad de agua, se puede predecir
    mejor el superplastificante necesario que al reves.

    Esto tiene sentido ingenieril: la cantidad de agua se decide primero
    en el diseno de la mezcla, y el superplastificante se ajusta en
    funcion del agua para lograr la trabajabilidad deseada.

  RESULTADO COMPLETO (BEST, 7 aristas):
    1. Water -> Superplasticizer          (BIC y AIC)
    2. FineAgg -> Water                   (BIC y AIC)
    3. CoarseAgg -> Cement                (BIC y AIC)
    4. Age -> Superplasticizer            (BIC y AIC)
    5. CoarseAgg -> Water                 (BIC y AIC)
    6. Cement -> FlyAsh                   (BIC y AIC)
    7. CoarseAgg -> Slag                  (BIC y AIC)

  En las 7 aristas de BEST y las 7 de WORST, BIC y AIC coinciden
  en el 100% de los casos. Esto confirma la robustez de las direcciones.
